# Frame PC — первая версия сайта

Адаптивный сайт-витрина для Frame PC: главная страница, каталог демонстрационных сборок, интерактивный конфигуратор и переключение RU/EN.

## Важно перед публикацией
- Цены, спецификации, индекс производительности и совместимость в этой версии демонстрационные. Это UI-прототип, не подключённый к WB/Avito и не являющийся офертой.
- Замените ссылку `https://t.me/framepcm` в `index.html` на актуальный контакт.
- Не используйте демонстрационные цены как реальные предложения.
- Переключатель RU/EN — основа для двух языков; переведён основной интерфейс, названия демонстрационных комплектующих пока могут оставаться на русском.

## Запуск на Windows

### Самый простой способ
1. Распакуйте архив в папку, например `C:\FramePC`.
2. Откройте `index.html` двойным щелчком в браузере.

Сайт работает без Python, npm, базы данных и сервера.

### Локальный веб-сервер (необязательно)
Если установлен Python:
1. Откройте папку сайта в Проводнике.
2. Кликните по адресной строке, введите `cmd` и нажмите Enter.
3. Выполните:
   ```bat
   python -m http.server 8000
   ```
4. Откройте `http://localhost:8000`.

## Публикация бесплатно через GitHub Pages
1. Создайте аккаунт на https://github.com (если его ещё нет).
2. Создайте новый публичный репозиторий, например `frame-pc`.
3. Загрузите в корень репозитория три файла: `index.html`, `style.css`, `script.js`.
4. Откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
7. Через некоторое время сайт появится по адресу вида `https://ВАШ-ЛОГИН.github.io/frame-pc/`.

GitHub Pages размещает статические сайты бесплатно. Он не запускает Python-скрипты, не хранит секретные токены и сам по себе не обновляет цены. Автопоиск WB/Avito — отдельный следующий этап.

## Файлы
- `index.html` — разметка страниц и контент.
- `style.css` — внешний вид и адаптивная верстка.
- `script.js` — фильтры, конфигуратор, расчёт, переключение языка.
