# Frame PC — сайт с редактируемым каталогом

В проект добавлен отдельный файл `products.json`: в нём хранятся готовые сборки и комплектующие для конфигуратора. `style.css` по-прежнему отвечает за внешний вид, `index.html` — за структуру, `script.js` — за логику.

## Как изменить цены и комплектующие

1. Открой `products.json` в редакторе текста (например, Блокнот или VS Code).
2. Найди нужный раздел в `components`: `cpu` — процессоры, `board` — материнские платы, `gpu` — видеокарты, `ram` — память, `storage` — накопители, `psu` — блоки питания, `case` — корпуса.
3. Измени `name` (название), `short` (короткое описание), `price` (цена в рублях) и `min` (бюджет сборки, с которого компонент может выбираться).
4. Чтобы добавить компонент, скопируй один объект в нужный массив и измени его поля. Следи за запятыми и кавычками — JSON чувствителен к синтаксису.
5. В массиве `builds` редактируются готовые сборки, которые показываются в каталоге: `name`, `price`, `desc`, `specs` и другие поля.
6. Сохрани файл и загрузи изменённый `products.json` в корень репозитория GitHub, заменив старый. Через некоторое время изменения появятся на `https://framepc.ru`.

## Как изменить дизайн

- `style.css` — цвета, шрифты, размеры, отступы, карточки и адаптивная вёрстка.
- `index.html` — тексты и структура секций. Некоторые тексты интерфейса также находятся в `script.js` в объектах `translations` (для русского и английского языков).
- `script.js` — логика фильтров, конфигуратора и переключения языка. Обычно для изменения цен этот файл трогать не нужно.

## Как открыть сайт локально

Поскольку каталог загружается через `fetch`, не открывай `index.html` двойным щелчком: браузер может заблокировать загрузку JSON.

Если установлен Python, открой папку проекта в Проводнике, введи `cmd` в адресной строке и выполни:

```bat
python -m http.server 8000
```

Затем открой `http://localhost:8000`. Либо проверяй изменения после загрузки файлов в GitHub Pages.

## Важно

Начальные цены и комплектующие — демонстрационные. Перед публикацией замени их на актуальные. Этот сайт не проверяет реальную физическую совместимость деталей и не получает цены автоматически из Wildberries или Avito. Каталог работает на статических файлах и не требует платного сервера.


### Контакты в карточках сборок

В каждой карточке есть кнопки Telegram и VK. Текст обращения включает название сборки, общую цену, комплектующие и описание. Telegram открывает чат с подготовленным черновиком сообщения; VK открывает чат и копирует текст в буфер, который нужно вставить в поле сообщения. В нижнем блоке контактов также есть обе кнопки. Для автоматического копирования сайт должен открываться через HTTPS (например, GitHub Pages).

### Мобильная версия

В `style.css` добавлены ограничения ширины и адаптивные стили для узких экранов, чтобы содержимое не растягивало страницу по горизонтали.
